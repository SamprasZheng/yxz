# OpenClaw

Open-source AI agent platform; formerly Moltbot / Clawdbot / NemoClaw. Created by [[entities/peter-steinberger]]. Became the most widely adopted open-source agent framework as of mid-2026.

## Naming history

| Date | Name |
|---|---|
| Nov 2025 | First published as Moltbot / Warelay |
| Jan 30, 2026 | Renamed OpenClaw; critical security vulnerability also disclosed |
| Feb 15, 2026 | Steinberger joins OpenAI as personal-agents lead |
| Aug 30, 2026 | Stable v2.0 (v2026.8.1) released under MIT license |
| Nov 2026 | 1-year anniversary; moving toward independent foundation |

## Key metrics (as of Apr 2026)

- 351,000+ GitHub stars
- 3.2 million monthly active users
- 44,000+ community-built skills

## Security concerns

- Critical vulnerability disclosed Jan 30, 2026 (same day as rename).
- Malware targeting the skills registry reported post-launch.

## NVIDIA integration

- [[entities/nvidia]] released [[sources/nemoclaw-build-a-claw-portal-2026|NemoClaw]] at GTC Taipei 2026 as an enterprise security/guardrails layer for OpenClaw.
