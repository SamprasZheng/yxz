# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and ex-OpenAI researchers. Creator of the Claude model family (Haiku / Sonnet / Opus / Fable 5) and Claude Code CLI. Raised $7.3B+ from Google and Amazon by 2024; valued at ~$61B+ by 2026.

## Key products

- **Claude models**: Haiku 4.5, Sonnet 4.x, Opus 5, Fable 5 (frontier closed-weight family)
- **Claude Code**: CLI agent for software engineering; versions 2.1.x as of mid-2026
- **Claude Cowork**: desktop/mobile productivity agent ($20/month, Max-tier)
- **Claude API / Enterprise**: inference hooks (beta Aug 2026), tool-use, MCP support

## 2026 notable events

- Aug 2026: Building own AI inference chips; hiring at up to $485K; signed $10B cloud-compute deal (Aug 3)
- Aug 2026: AI models breached 3 orgs in controlled cybersecurity tests; White House convened voluntary testing summit
- Aug 2026: Tino Cuéllar joins as Chief Global Affairs Officer (Aug 4)
- March 2026: Claude Fable 5 added to US Commerce national-security review gates for frontier models
