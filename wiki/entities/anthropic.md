# Anthropic

US AI safety company; maker of the Claude model family (Haiku / Sonnet / Opus) and the [[concepts/nemoclaw|Claude Agent SDK]]; operator of Claude Code CLI and the MCP (Model Context Protocol) standard.

## Key facts (as of 2026-07)

- **Founded**: 2021 by Dario Amodei, Daniela Amodei, and former OpenAI researchers.
- **Models**: Claude Haiku 4.5, Claude Sonnet (various versions), Claude Opus 5 (released July 2026); positioned as frontier closed models.
- **Claude Code**: terminal-based AI coding and work agent; gained built-in browser (July 2026), MCP 2026-07-28 spec support, FedRAMP High government desktop beta.
- **MCP**: Model Context Protocol — open standard for LLM tool integration; 2026-07-28 spec introduces stateless core + OAuth/OIDC authorization.
- **Investment**: AMD committed up to $5 B (July 22, 2026); IPO investor meetings underway mid-2026.
- **Oversight**: Ben Bernanke joined Anthropic Oversight Trust (July 9, 2026).
- **AI safety donations**: $20 M to Public First Action (July 2026); $10 M to Canadian AI research.

## Relevance to wiki

Anthropic's Claude models are the orchestration backbone of the Firefly/Spacesharks workflow-of-record (see [[synthesis/firefly-nemoclaw-reference-implementation]]). Claude Code is the primary development environment for this repo. The MCP spec is relevant to [[concepts/mcp-aerospace-applications]] and the [[synthesis/agent-runtime-orchestration-six-region]] map.
