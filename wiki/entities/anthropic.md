# Anthropic

US AI safety company (PBC); founded 2021 by Dario Amodei, Daniela Amodei, and former OpenAI researchers. Builds the [[concepts/nemotron|—]] Claude model family. Anthropic's stated mission is AI safety research and the responsible development of AI for long-term benefit.

## Key products

- **Claude** model family: Haiku / Sonnet / Opus / Fable tiers; as of July 2026 the flagship is **Claude Opus 5** (released July 24–27, 2026) and the default free/pro model is **Claude Sonnet 5** (since July 1, 2026).
- **Claude Code**: agentic coding CLI with MCP integration, nested subagents, remote control, and dynamic workflows.

## Notable 2026 events

- **Claude Opus 5 (July 2026):** doubles Frontier-Bench v0.1 vs Opus 4.8; 3× ARC-AGI 3; surpasses Fable 5 on OSWorld 2.0 at one-third the cost; same $5/$25 per million token pricing.
- **AMD compute deal (July 2026):** up to 2 GW of MI450/Helios-generation compute; up to $5 B Anthropic equity stake in AMD.
- **MCP 2026-07-28 spec:** Anthropic co-leads the Model Context Protocol ecosystem; Claude Code updated for the new stateless-core/OAuth-OIDC spec on release day.

- **AI slowdown letter (July 28, 2026):** Anthropic employees among 1,100+ signatories across OpenAI/Anthropic/Google/Meta.
