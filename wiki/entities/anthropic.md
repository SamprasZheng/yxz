# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and former OpenAI researchers. Builder of the Claude model family (Haiku / Sonnet / Opus / Fable / Mythos lineages). Developer of Claude Code (agentic coding CLI), the Claude Agent SDK, and the x402-compatible Claude API.

## Key facts

- **Founding:** 2021; HQ San Francisco CA; Amazon and Google anchor investors.
- **Models (2026):** Claude Fable 5.2 + Mythos 5.2 launched November 2026 as most capable generation; Fable 5.2 set as default Fable model in Claude Code v2.1.321.
- **IPO:** Filing Nov 2026 at $70–78/share on Nasdaq ticker "ANT"; 825M shares; pricing Nov 18, first trading expected Nov 19; reportedly ~6× oversubscribed; MSCI index inclusion targeted Nov 30. Potentially the largest-ever US first-time share sale (Bloomberg, 2026-11-16).
- **Products:** Claude (chat + API), Claude Code CLI (v2.1.325 as of Nov 13 2026), Claude Agent SDK, Projects (team coordinator), Claude Meetings (Google Meet integration, beta Nov 2026).
- **Policy:** US export controls on Mythos model keeping foreign firms in limbo as of Nov 2026.
