# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and others (ex-OpenAI). Creator of the Claude model family and Claude Code CLI.

## Key facts

- **Valuation:** $965B (post $65B Series H, August 2026)
- **ARR:** $47B–$80B (per SaaStr.ai, mid-2026)
- **IPO:** Roadshow beginning September 2026; Oct 2026 target listing; book-runners Morgan Stanley, Goldman Sachs, JPMorgan
- **Models:** Claude family (Haiku, Sonnet, Fable, Mythos/Opus lineages); safety-focused RLHF training
- **Products:** Claude Code (agentic CLI), Claude Security (codebase security scanning), Claude for Teachers (edu pilot)
- **Key partnerships:** Salesforce ("Claudeforce" embedding Claude in Salesforce products, Sept 2026)
