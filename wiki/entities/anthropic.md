# Anthropic

**Anthropic PBC** (Public Benefit Corporation) is a US AI safety company founded 2021 by former OpenAI researchers (Dario Amodei, Daniela Amodei, et al.), building the **Claude** family of large language models and the **Claude Code** agentic coding assistant.

## Key Products

| Product | Notes |
|---|---|
| Claude (Fable / Opus / Sonnet / Haiku) | Flagship closed-frontier LLM family; Fable 5.1 and GPT-6 Astra tied at ≈53 on AA-Index v4.3 (Sept 2026) |
| Claude Mythos | High-capability model; access restricted to vetted cybersecurity + biomedical organizations |
| Claude Code | Agentic CLI + IDE tool; v2.1.328 as of Nov 2026 |
| Managed Agents | Server-hosted agent service; self-hosted option released Nov 12, 2026 |

## 2026 Timeline

- **Nov 9, 2026:** Claude Fable 5.2 + Mythos 5.2 released.
- **Nov 10, 2026:** IPO roadshow launched — 825M Class A shares, $70–78/share target, Nasdaq ticker **ANT**.
- **Nov 12, 2026:** Self-hosted Managed Agents released.
- **Nov 19, 2026:** Claude Code 2.1.328; Code Mode (experimental) added.
