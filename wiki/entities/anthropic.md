# Anthropic

US AI safety company; creator of the Claude model family and [[concepts/claude-code-platform|Claude Code]] developer platform. Founded 2021 by Dario Amodei, Daniela Amodei, and other OpenAI alumni.

## Key facts (2026)

- **$30B Series G** closed 2026; run-rate revenue >$2.5B (doubled since Jan 1, 2026)
- **Claude Code**: ~90% of Anthropic's own code is generated by Claude Code; Claude Code was itself built by Claude Code — recursive self-compounding in production
- Weekly active users of Claude Code doubled since Jan 2026
- Developer conference "Code with Claude 2026" expanded to Tokyo (June 10) + two other cities; keynote free-streamed globally
- [[concepts/nemotron]] + [[concepts/nemoclaw]] referenced as competing open-weight/agent stacks to Anthropic's Claude/Claude Code offering

## Model family (2026)

- Claude Haiku 4.5 → Claude Sonnet → Claude Opus → Claude Fable 5.1 (flagship as of Sept 2026)
- Fable 5.1 scored 53 on AA Index v4.3 (Sept 2026), tied with GPT-6 Astra for closed-frontier #1
