# Anthropic

AI safety company (San Francisco, founded 2021 by Dario Amodei, Daniela Amodei et al., ex-OpenAI). Builds the Claude model family, Claude Code (agentic coding CLI + Agent SDK), and enterprise AI products. Estimated ~$965B private valuation (May 2026 Series H-1); targeting a ~$2T public valuation in a planned October 2026 IPO.
