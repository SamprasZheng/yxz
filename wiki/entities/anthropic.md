# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and ex-OpenAI researchers. Creator of the Claude model family and Claude Code (agentic coding CLI).

## Key products

- **Claude models** — Claude 5 family (Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5); closed frontier as of 2026-09
- **Claude Code** — agentic CLI for software engineering; v2.1.290 adds Mods (TypeScript plugin hooks) + Projects beta (parallel threads)
- **Claude Agent SDK** — building custom agents and multi-agent systems

## Positioning (2026)

- Barclays targeting 50 % of developer population on Claude Code by end 2026
- Project Glasswing: 129 K+ software vulnerabilities found Apr–Jul 2026 via expanded vetted-cybersecurity access program
- Expanding Claude Startups program for founders and fast-growing teams
