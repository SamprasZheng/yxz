# Anthropic

US AI safety company and model developer. Maker of the Claude model family. Founded 2021 by ex-OpenAI researchers including Dario Amodei (CEO) and Daniela Amodei (President). Public Benefit Corporation.

## Key products

- **Claude model family** — flagship; tiers include Haiku, Sonnet, Opus, Fable, Mythos; Claude Fable 5.2 + Mythos 5.2 released Nov 9, 2026
- **Claude Code** — CLI/IDE coding agent; v2.1.327 as of Nov 17–18 2026; Code Mode for agent teams added in Nov
- **Claude Agent SDK** — part of the US-led open agent-runtime ecosystem
- **Claude API** — developer platform (Messages API, Tool Runner, Managed Agents)
