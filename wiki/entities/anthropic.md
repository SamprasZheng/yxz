# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and colleagues from OpenAI. Builds the Claude model family (Haiku / Sonnet / Opus / Fable series). Revenue run rate $65B annualized as of August 2026 (Q2 2026: $11.5B, +14× YoY); October 2026 IPO targeting ~$2 trillion valuation reported. Operates Claude Code (agentic CLI + remote sessions), Cowork (collaborative workspace), and the Anthropic API / Claude Agent SDK. "Model 2" — an internal model more capable than Mythos — will not be publicly released per August 2026 reporting.
