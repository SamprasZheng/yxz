# Anthropic

US AI safety company (founded 2021, Dario Amodei / Daniela Amodei); creator of the Claude model family (Haiku / Sonnet / Opus / Fable / 5.x generation); Claude Code CLI + Agent SDK. Headquartered San Francisco. IPO process active as of late 2026 (valuation target reportedly repriced from $2T to $1.5–1.6T). Primary peer to OpenAI in the frontier-closed-model race.

## Key products
- **Claude model family** — closed frontier models (Haiku 5.5 / Sonnet 5.5 / Opus 5.5 / Fable 5.1 as of late 2026)
- **Claude Code** — agentic CLI and SDK for software development; Agent SDK v2.x; MCP / hook integrations
- **Anthropic API** — Messages API, Tool Runner, Managed Agents, prompt caching

## November 2026 snapshot
- Claude Code v2.1.319 adds background MCP tasks and expanded auto-mode/gateway controls
- Game-clone restrictions added to Claude Code + Opus 5.5 combination (IP-infringement policy)
- Claude Code product lead Cat Wu departed to OpenAI
- Goldman Sachs restricted Claude Code to ~12,000 engineers (traders and bankers excluded)
- 40-minute partial API outage during November
- IPO valuation reportedly repriced down to $1.5–1.6T on AI-stock selloff
