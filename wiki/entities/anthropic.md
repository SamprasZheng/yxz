# Anthropic

US AI safety company; creator of the Claude model family (Haiku / Sonnet / Opus / Fable / Mythos lines) and Claude Code. Founded 2021 by Dario Amodei, Daniela Amodei, and colleagues from OpenAI. Headquarters: San Francisco.

## Key products (2026)

- **Claude models** — Sonnet 4.6, Opus 5, Fable 5.1, Mythos 5.1; primary closed-frontier LLM line.
- **Claude Code** — CLI and agentic coding tool; available as CLI, desktop app, web (claude.ai/code), and IDE extensions.
- **Enterprise Frontier Safeguards (EFS)** — zero data retention + customer-cloud misuse-detection, announced 2026-09-01.
- **Project Glasswing** — enterprise cybersecurity flaw-finding product.

## Positioning

US closed-frontier LLM leader alongside OpenAI/Google; Fable 5 (62.1) and Opus 5 (63.0) sit atop the closed-weight leaderboard in the [[synthesis/open-weight-llm-agent-stack-six-region]] six-region map (open-weight gap now ~3 pts vs Kimi K3 / GLM-5.3 at 60).
