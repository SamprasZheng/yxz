# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and other ex-OpenAI researchers. Builder of the Claude model family (Haiku / Sonnet / Opus / Fable lineage). Headquarters: San Francisco, CA.

## Key products

- **Claude** — primary model family; Sonnet 5 now default in Claude Code (August 2026) with 1M-token context.
- **Claude Code** — CLI and IDE agent for software engineering; the primary development surface for the Spacesharks / Firefly stack.
- **Claude API / Anthropic SDK** — Messages API, tool-use, prompt caching, MCP integration.

## Notable facts

- **2026 IPO preparations** — Wilson Sonsini engaged; investment banks in preliminary talks (as of August 2026). 300K+ business customers; large accounts grew over 7× YoY.
- **Cognizant partnership** — Expanded July 27, 2026 for EMEA enterprise Claude deployments.
- **Competitive pressure** — Alibaba Qwen3.8-Max (August 3, 2026) claims benchmark parity with Claude.
