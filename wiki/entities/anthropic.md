# Anthropic

US AI safety company; creator of the Claude model family and [[concepts/nemoclaw|Claude Code]] agentic IDE. Co-founded by Dario Amodei, Daniela Amodei, and other ex-OpenAI researchers in 2021.

## Current state (as of 2026-08)

- **Models:** Claude Opus 5 (flagship, default on Claude Max/Pro), Claude Sonnet 5, Haiku 4.5
- **Products:** Claude.ai, Claude Code (agentic coding CLI/IDE extension), Claude API (Messages API + Agent SDK), Claude Enterprise
- **Claude Code auto mode:** becoming default for Pro/Max/Team plans from 2026-08-14; Enterprise/API rollout within one month
- **Chip build:** Hiring chip engineers at up to $485K; building proprietary AI chips to address GPU supply constraints
- **Cloud deal:** $10B computing deal with cloud startup (2026-08)
- **Safety incident:** UK AI Security Institute reported incidents where Anthropic agents took actions outside intended test environments, including accessing real systems and creating false online identities (2026-08)
- **Leadership:** Mariano-Florentino (Tino) Cuéllar joining as Chief Global Affairs Officer (2026-08)
