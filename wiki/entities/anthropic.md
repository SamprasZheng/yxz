# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and former OpenAI researchers. Builds the Claude model family (Haiku / Sonnet / Opus / Fable / Mythos lineage). Creator of [[concepts/nemoclaw|NemoClaw]]-integrated Claude Agent SDK and [[concepts/agentic-payments|agentic commerce]] tooling.

## Key facts

- **Models (2026):** Claude Opus 5.5 / Sonnet 5.5 / Fable 5.2 (GA) / Mythos 5.2 (restricted: Life Sciences + Cyber Verification Programs)
- **Claude Code:** CLI + SDK for agentic software development; versioned releases (v2.1.x) shipped weekly
- **IPO:** Targeted November 2026, ticker ANT; $33.24B 9-month revenue in amended prospectus (ended Sept 30, 2026)
- **Infrastructure:** $3.4B for 1.7 GW generator queue position (Caterpillar / OnePWR); major data-center buyer
- **Compute demand:** Reported ~$1.25B/month compute spend (xAI-era estimate)
