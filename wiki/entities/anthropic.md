# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and other former OpenAI researchers. Creator of the Claude model family and the Claude Code developer platform.

## Key facts

- Flagship models: Claude Fable 5.1, Claude Mythos 5.1 (as of Sept 2026)
- Core product lines: Claude (API + consumer), Claude Code (CLI + IDE agent), Cowork (team collaboration)
- Safety framing: Constitutional AI, responsible scaling policy, monthly threat-intelligence reports
- Revenue run rate: $30B+ (1,400% YoY as of mid-2026); October 2026 IPO at ~$800B valuation in planning
- Salesforce partnership ("Claudeforce"): Claude embedded in Agentforce, Slack, CRM (open beta Sept 2026)

## Relevance to this wiki

- Primary model provider for the Spacesharks Mission Desk (via Claude Agent SDK / Anthropic API)
- [[concepts/tiered-inference]] references Anthropic prompt caching as a cost-reduction lever
- Claude Code is the development environment for this repo; `claude-opus-4-7` appears in `agents/nemo_workflow.yaml` (doc-only lag per [[synthesis/firefly-nemoclaw-reference-implementation]])
