# Anthropic

US AI safety company (founded 2021, Dario Amodei + Daniela Amodei + team from OpenAI). Developer of the Claude model family (Haiku / Sonnet / Opus / Fable / Mythos lineages) and Claude Code (agentic CLI + SDK). Headquartered in San Francisco.

**Key products:** Claude API, Claude Code, Claude.ai consumer app, Claude Enterprise.

**November 2026 milestone:** IPO roadshow launched 2026-11-10 — 825M shares at $70–78/share targeting Nasdaq "ANT"; Claude Fable 5.2 and Mythos 5.2 released 2026-11-09.

**Relevance to this wiki:** Claude Code is the runtime agent for Firefly, Spacesharks GPTs, and the kol-daily-digest routine. Nemotron / NemoClaw stack interfaces with Anthropic Claude as a fallback provider.
