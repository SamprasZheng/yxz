# Anthropic

US AI safety company founded 2021 by Dario Amodei, Daniela Amodei, and ex-OpenAI researchers. Develops the Claude family of LLMs (Haiku / Sonnet / Opus / Fable) and Claude Code (agentic CLI). Core thesis: frontier AI safety research must be paired with frontier capability research.

Key products: Claude API, Claude Code (auto-mode default Aug 2026), Claude for Science (10k free seats), Claudeforce (Salesforce partnership, open beta Sept 2026).

Pricing milestones: Sonnet 5 intro pricing ($2/M) → standard ($3/M) effective 2026-09-01.
