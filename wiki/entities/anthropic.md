# Anthropic

US AI safety company (founded 2021 by Dario Amodei, Daniela Amodei, and former OpenAI colleagues); creator of the Claude model family. Canonical for the closed-frontier AI lab archetype in [[synthesis/open-weight-llm-agent-stack-six-region]].

## Key products
- **Claude** model family: Haiku (fast/cheap), Sonnet (balanced), Opus (frontier reasoning), Fable (creative/specialized)
- **Claude Code** — agentic coding CLI + IDE extension + web product; the agent runtime used in the [[synthesis/firefly-nemoclaw-reference-implementation]] workflow
- **Claude API / Anthropic SDK** — Messages API, tool use, prompt caching, managed agents

## 2026 milestones
- Claude Opus 5 released as default on Claude Max (Jul 2026)
- Fable 5 returned globally Jul 1 2026
- AMD strategic partnership announced (up to $5B investment as milestones are reached) — hardware diversification beyond NVIDIA
- Claude Code entered FedRAMP High Government Desktop public beta (Jul 2026)
- Proposed industry-wide jailbreak severity scoring framework with Amazon/Microsoft/Google
