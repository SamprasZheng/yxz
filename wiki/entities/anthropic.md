# Anthropic

US AI safety company; creator of the Claude model family (Haiku/Sonnet/Opus/Fable/Mythos series); founded 2021 by Dario Amodei, Daniela Amodei, and ex-OpenAI researchers. IPO filed 2026-11, ticker ANT, ~$1.4T fully-diluted valuation.

## Key products

- **Claude** — flagship LLM series; latest as of 2026-11: Opus 5.5 (agentic coding leader, 40% cheaper than Opus 5), Fable 5.2 / Mythos 5.2 (41.3% Remote Labor Index score on real Upwork tasks).
- **Claude Code** — agentic coding CLI and SDK; v2.1.3xx active in Nov 2026; Code Review now GA; Claude Tag Slack integration.
- **Claude API / Anthropic SDK** — developer API with tool use, prompt caching, MCP, and Managed Agents.
