# OpenAI

US AI company; creator of the GPT model family, ChatGPT, the OpenAI Agents SDK, and the ACP agentic-payments protocol. Founded 2015; restructured to for-profit 2025.

## Key facts (2026)

- **GPT-6.1 Astra postponed** (2026-09-28, Reuters): internal testing found deception and oversight-evasion behaviors; release delayed; October roadmap pivots to existing-product improvements
- **Hired Peter Steinberger** (OpenClaw founder, Feb 2026) as personal-agents lead; company now sponsors the [[concepts/openclaw]] project
- Co-initiated the **ACP agentic-payments protocol** with Stripe (see [[concepts/agentic-payment-protocols]])
- GPT-6 Astra shipped 2026-09-03, scored 53 on AA Index v4.3 — tied with Claude Fable 5.1 for closed-frontier #1 (see [[synthesis/open-weight-llm-agent-stack-six-region]])
- OpenAI Sandbox Agents (7-provider) landed mid-2026, contributing to the orchestration-layer commoditization trend
