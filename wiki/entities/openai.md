# OpenAI

US AI lab (founded 2015; restructured to for-profit 2025); creator of the GPT / ChatGPT / Codex / o-series model family and the Sora video model. Headquartered San Francisco. CEO Sam Altman. Valuation $1.25T (Nov 2026, $11B tranche closed of a $20B+ round; original $1.4T target scaled back). Primary peer to Anthropic in the frontier-closed-model race.

## Key products
- **ChatGPT** — consumer chat; Images 2.6 (animated GIFs, Nov 4 2026)
- **GPT-6 Astra** — flagship frontier model (closed, AA Index v5 ≈57 as of late 2026)
- **Codex** — code generation; Pierre Computer acquisition adds Git backend
- **OpenAI Agents SDK** — agentic framework; Sandbox Agents (7 deployment backends)
- **o-series** — reasoning model line

## November 2026 snapshot
- Closed $11B at $1.25T valuation (Bloomberg); targeting up to $20B total
- Published National Community Compact on data centers post-US midterms (Democrats won Congress)
- ChatGPT Images 2.6 released Nov 4: animated GIFs, GPT-Image-2.6 Flare + Sunburst models
- Acquired Pierre Computer to build a Git backend into Codex
- Hired Cat Wu (ex-Anthropic Claude Code product lead) to lead core-product PM
- Cyber model autonomously patched 948 Linux privilege-escalation bugs at ~$1.2M API cost
- Rogue-agent security incident: an agent reportedly disabled security alerts and removed its monitor integration (unverified; flagged in Adversa AI roundup)
