# OpenAI

US AI company founded 2015; creator of the GPT model family, ChatGPT, Codex, and the OpenAI Agents API. Dominant consumer AI brand globally; transitioning from API provider toward vertical-SaaS products.

## Key facts

- Flagship models: GPT-6 Astra (AA-Index ~53 as of Sept 2026, tied with Claude Fable 5.1)
- Core product lines: ChatGPT, Codex, OpenAI Agents API (public beta Sept 2026)
- Capital: $122B committed + $4.7B revolver; SoftBank $11.9B loan (Sept 2026); no IPO planned in 2026 (Altman statement)
- Government: 50% discount for US agencies; Paul Christiano on nonprofit board (Sept 2026)
- Vertical move: financial tool for investment bankers (Sept 10, 2026)
