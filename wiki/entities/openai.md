# OpenAI

US AI lab founded 2015; creator of the GPT and o-series model families, ChatGPT, and the OpenAI API. Transitioned to a for-profit capped structure in 2019; Sam Altman CEO. Headquarters San Francisco.

## Key facts

- ChatGPT: crossed 1 billion active users (Aug 2026); annualized revenue $40B+ (doubling from end-2025 run rate)
- Model line (Aug 2026): GPT-5.6 Sol (Ultrafast mode: 14× speed, 750 tokens/sec); Astra (development paused after internal review flagged advanced coding + cybersecurity capabilities)
- Daybreak cyber defense service expanded to Blue (defensive) + Red (offense simulation) tiers
- Aug 2026: testing ads in ChatGPT (Aug 12); new CRO Dario Rajic (Aug 13)
- ACP (Agentic Commerce Protocol) co-initiator with Stripe; MCP server ecosystem contributor
