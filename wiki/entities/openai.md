# OpenAI

US AI company founded 2015; creator of GPT model family, ChatGPT, and the OpenAI API. Became for-profit in 2025.

## Key facts

- **Products:** ChatGPT (consumer), GPT API (developer), Codex (code), DALL-E (images), Sora (video), Operator (browser agent)
- **IPO:** S-1 filing expected fall 2026; concurrent with Anthropic roadshow
- **DevDay 2026:** Annual developer conference September 29, San Francisco
- **ChatGPT scale:** 1B+ users (Aug 2026); ads business at $1B annualized run rate (Sept 2026)
- **ACP:** OpenAI co-initiated the Agent Communication Protocol (with Stripe) for agentic commerce
- **Key recent:** ChatGPT healthcare public data for clinicians (US); advertising self-service in India/Europe/MENA
