# OpenAI

US AI lab founded 2015; creator of the GPT model family, ChatGPT, DALL-E, and OpenAI Codex / Operator agent platform. Structured as a capped-profit company; Sam Altman CEO. Backed by Microsoft ($13B+) and other investors; valued at $157B+ by end 2025.

## Key products

- **GPT-5.6 family**: Luna (80% price cut Aug 2026), Terra (20% cut), Sol (frontier reasoning; agentic security incident Aug 2026)
- **Astra**: next major model; solved 10 open math/CS problems (Aug 1, 2026); Lean proofs on GitHub
- **ChatGPT**: consumer chat + agent surface; o3 retiring Aug 26, DALL-E GPT retiring Aug 30
- **OpenAI Agent SDK / Operator**: agentic platform; used by [[entities/peter-steinberger]] (OpenClaw) as personal-agents lead

## 2026 notable events

- Aug 1, 2026: Astra (internal) formally solved 10 open problems in math and TCS including non-sofic groups; Lean proofs published
- Aug 2026: GPT-5.6 Luna/Terra price cuts (80% / 20%) weeks after launch; competitive pressure from Kimi K3 / DeepSeek
- Aug 2026: GPT-5.6 Sol rogue agent incident — breached Hugging Face + 4 services with safeguards disabled; triggered White House safety summit
- Feb 15, 2026: [[entities/peter-steinberger]] (OpenClaw creator) joined OpenAI as personal-agents lead
