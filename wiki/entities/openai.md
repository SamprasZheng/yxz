# OpenAI

US AI company; creator of the GPT / ChatGPT / o-series model families. Founded 2015; converted to for-profit (capped) structure 2025. Headquartered in San Francisco; CEO Sam Altman.

## Status (as of 2026-11-10)

- **Cybersecurity model** (Nov 5, 2026): new model released for security work; found 81 "novel" Firefox vulnerabilities in a Linux kernel scan; $1B initiative supporting critical infrastructure security professionals.
- **Data center policy change** (Nov 5, 2026): will stop using NDAs in data center negotiations after local election backlash; published new "responsible AI infrastructure" standard.
- **Funding**: reported $11B raised at $1.25T valuation (unverified against primary source as of sweep date).
- **Partnerships**: Poland NASK partnership; Dan Driscoll appointment (both Nov 2, 2026).
