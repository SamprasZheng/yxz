# OpenAI

US AI company founded 2015; creator of ChatGPT, GPT model family, and the Agents API. Largest consumer AI platform by user count as of 2026.

## Key products (2026)

- **GPT-6 Astra** — flagship closed model; AA Index ~53 (v4.3, Sept 2026)
- **GPT-6.1 Sol** — launched Oct 2026 at $2/$10; ~= Astra performance at lower cost
- **Agents API** — persistent agent workflows, computer use, cloud-based coding (DevDay 2026)
- **OpenAI Sandbox Agents** — 7-provider commoditized sandbox offering
- **ACP (Agent Communication Protocol)** — co-initiated with Stripe; agentic commerce protocol

## Business (2026)

- Seeking ~$30 B funding round (UAE sovereign funds + BlackRock)
- API tier restructure: Build / Launch / Grow (Grow now at $500 total payments, down from $1 K)
- Three-tiered paid structure reducing developer friction
