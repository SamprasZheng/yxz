# OpenAI

**OpenAI** is a US AI company (founded 2015 as a nonprofit, restructured 2019 as a capped-profit) building the **GPT** and **o-series** LLM families, **ChatGPT**, and the **Codex** coding agent. [[entities/peter-steinberger]] ([[concepts/openclaw]]) joined OpenAI as a personal-agents lead in Feb 2026.

## Key Products

| Product | Notes |
|---|---|
| GPT-6.2 Astra / Sol | Released Nov 2026; targets professional work and reduced inference cost for complex tasks |
| ChatGPT | Consumer AI assistant; Wallet (US Pro) + Images 2.6 added Nov 2026 |
| Codex | AI coding agent; Git backend in development via Pierre Computer acquisition |
| OpenAI Agent SDK | Framework used in the US open-ecosystem agent layer |
