## FOM (Figure of Merit) Formula

Defined here for future runs to iterate on:

```
FOM(ticker) = 0.4 × confidence
            + 0.3 × normalized_sizing_sigma
            + 0.2 × recent_hit_rate
            + 0.1 × news_momentum
```

Where each component is normalized to [0, 1]:

| Component | Normalization | Source |
|-----------|--------------|--------|
| `confidence` | Raw model output 0→1 | Scan verdict |
| `normalized_sizing_sigma` | `(σ − min_σ) / (max_σ − min_σ)` across watchlist | Scan verdict |
| `recent_hit_rate` | Rolling 5-day hit rate 0→1 | Backtest log |
| `news_momentum` | Normalized news-scout score 0→1 | news_scout agent output |

## FOM Weights Rationale

- **0.4 × confidence** — heaviest weight because the model's stated certainty is the primary forward signal; directional calls with low confidence should size small.
- **0.3 × sizing_sigma** — second-heaviest: position size already encodes a risk-adjusted conviction view from the scan agent.
- **0.2 × recent_hit_rate** — backward-looking calibration; a model that was right 4/5 last days earns more weight than one at 1/5.
- **0.1 × news_momentum** — lightest: news is fast-decaying signal, useful for breaking ties, not as a primary driver.

Open question: whether to add a **reversal penalty** (subtract 0.05 per consecutive same-direction call that missed) to punish overconfident streaks.
